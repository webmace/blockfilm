📺 Tagesvideo für YouTube

    
Jeden Tag sucht die KI ein neues Thema und macht alles fertig zum Hochladen: Video (4K), Vorschaubild und eine Datei YouTube.txt mit Titel, Beschreibung und Schlagwörtern. Jeder Tag bekommt einen eigenen Ordner. Du lädst das Video in YouTube Studio hoch und kopierst den Text hinein.

    

      
      

    
Der Computer muss dafür an sein (ein Film braucht etwa 1–2 Stunden). Eigene Themen: eins pro Zeile in ~/Blockfilm/tagesthemen.txt, sonst sucht die KI selbst eins.

    

    

    

    

    

      Für Fortgeschrittene: automatisch auf YouTube hochladen
      
Nicht nötig. Wer will, kann Blockfilm erlauben, das Video selbst privat hochzuladen. Dafür braucht es einmalig einen Zugang aus der Google Cloud:

      
    
        
  1. Öffne die Google Cloud Console, melde dich mit dem Google-Konto deines Kanals an und lege ein neues Projekt an (z. B. „Blockfilm“).
    2. 
        
  2. Unter APIs & Dienste → Bibliothek die YouTube Data API v3 suchen und aktivieren.
    3. 
        
  3. Unter Google Auth Platform: App-Name „Blockfilm“, deine E-Mail, Zielgruppe Extern. Danach bei Zielgruppe auf „App veröffentlichen“ klicken, sonst läuft die Anmeldung nach 7 Tagen ab.
    4. 
        
  4. Unter Clients einen OAuth-Client vom Typ Desktop-App erstellen und die JSON-Datei herunterladen.
    5. 
        
  5. Den Inhalt der Datei hier einfügen und speichern:
    6. 
      

      

      

      
Beim Verbinden warnt Google „Diese App wurde nicht überprüft“: auf Erweitert → Zu Blockfilm wechseln klicken, das ist deine eigene App. Die Zugangsdaten bleiben nur auf diesem Computer.

      

    

  






  

    
🤖 KI einrichten

    
Damit die KI Filme schreiben kann, braucht Blockfilm einen API-Schlüssel von Anthropic (die Firma hinter der KI Claude).

    
    
      
  1. Ein Erwachsener öffnet console.anthropic.com und meldet sich an.
    2. 
      
  2. Unter Billing etwas Guthaben aufladen. Ein Film kostet ungefähr 10–15 Cent.
    3. 
      
  3. Unter API Keys einen neuen Schlüssel erstellen und ihn hier einfügen. Er beginnt mit sk-ant-.
    4. 
    

    

    

    
Der Schlüssel wird nur auf diesem Computer gespeichert (in ~/Blockfilm/einstellungen.json).

    

    

  






  

    
🗣 Aussprache verbessern
